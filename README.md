# Belu Vitullo · Landing de formación

Landing estática (HTML + CSS, sin build) de la formación de Prof. Mg. Lic. María Belén Vitullo.

## Estructura

```
index.html          # contenido de la página
assets/styles.css   # estilos
```

## Editar

Todo el texto está en `index.html`. Cada tarjeta de formación es un `<article class="card">`.
Colores y tipografías están en `assets/styles.css`.

## Ver en local

Abrir `index.html` en el navegador, o `npx serve .`

## Deploy

GitHub Pages desde la rama `main` (raíz). Cada `git push` actualiza el sitio.
